01 / THE BASICS

WHAT IS CODING?

Coding is writing instructions that tell a computer what to do. People use code to build websites, create apps, make games, and solve problems. A browser reads website code and turns it into the pages you see and interact with.

THE STRUCTURE

HTML

HTML stands for HyperText Markup Language. It organizes the content on a webpage, like headings, paragraphs, links, and images.

<h1>My Website</h1>
<p>Welcome!</p>

THE DESIGN

CSS

CSS stands for Cascading Style Sheets. It controls how a webpage looks, including colors, fonts, spacing, and layouts.

h1 {
  color: white;
}

JavaScript

JavaScript adds behavior to a webpage. It can respond to clicks, update information, and make interactive tools.

  alert("Hello!");
